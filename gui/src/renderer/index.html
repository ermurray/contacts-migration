Contacts Migration

Move contacts from an old account to a new one — backup, verify, then delete the old copies.

1 Old contacts export

Export the old contacts to a .vcf (iPhone: share contacts; or Contacts.app ▸ File ▸ Export ▸ vCard), then choose it here.

No file chosen

2 Back up

Writes a human-readable CSV and a lossless copy of your export.

3 Snapshot current contacts macOS

Records what's already on this Mac so the old copies can be removed precisely later. May ask for Automation permission.

4 Import into the new account

System Settings ▸ Contacts ▸ Default Account = new iCloud, then Contacts.app ▸ File ▸ Import your old .vcf. Wait for it to sync.

5 Verify

Export the new account to a fresh .vcf and choose it. We confirm every old contact is present.

6 Delete old copies

Locked until you have a backup and a passing verification.
